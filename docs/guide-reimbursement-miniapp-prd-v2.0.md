# 导游个人报账助手 微信小程序 PRD

- **文档版本**：V2.0
- **编制日期**：2026年04月25日
- **文档状态**：正式版

---

## 史诗（Epic）

**Epic-01：** 作为一名导游，我希望在微信小程序中轻松完成报账单的填写，通过上传模板、拍照识别及语音录入，自动生成与原模板格式完全一致的报账单，从而将繁琐的填单时间从 2 小时缩短至 10 分钟以内。

---

## 用户故事（User Stories）

### 模块一：登录与账号

#### US-01：微信一键登录

**作为** 导游  
**我想要** 通过微信一键登录小程序  
**以便** 无需填写额外信息，立即开始使用。

**验收标准：**
1. 打开小程序，若未登录，首屏显示「微信用户一键登录」按钮。
2. 点击按钮后，调用微信开放接口（`wx.login`）获取授权，静默完成登录。
3. 登录后默认持久化登录态，下次打开无需重复验证。
4. 提供「手机号验证码登录」作为备用方案，支持输入手机号获取验证码登录。

---

### 模块二：报账模板管理

#### US-02：上传个人报账模板

**作为** 导游  
**我想要** 将我常用的 Excel 报账模板上传至小程序  
**以便** 生成的报账单能完全符合我所服务的不同旅行社的格式要求。

**验收标准：**
1. 在「我的模板」页面，可上传手机本地或聊天文件中的 `.xlsx` / `.xls` 文件（<5MB）。
2. 上传后系统自动解析模板，识别「固定区域」与「空白可填区域」，保留所有合并单元格与样式。
3. 解析完成生成预览图，供导游确认模板无误。
4. 若上传非 Excel 文件或解析失败，明确提示错误原因，不闪退。

#### US-03：多模板管理

**作为** 导游  
**我想要** 管理多个不同的报账模板  
**以便** 在带不同类型团或为不同机构服务时，能灵活选择对应的模板新建报账单。

**验收标准：**
1. 模板列表展示所有已上传模板，支持重命名与删除操作。
2. 删除操作须二次确认，防止误删。
3. 新建报账单时，第一步必须从模板库中选择一个生效模板。

---

### 模块三：团信息录入

#### US-04：上传行程单并 OCR 识别填充

**作为** 导游  
**我想要** 上传行程单（拍照或文件），让系统自动识别并填写团号、日期、人数等信息  
**以便** 省去手动输入团基础信息的繁琐过程。

**验收标准：**
1. 选定模板后，进入「团信息」填写页，提供「上传行程单」入口。
2. 支持拍照、从相册或聊天文件上传图片/Excel 行程单。
3. 系统（通过 OCR/文字解析）自动提取：团号、导游姓名、出团/返程日期、司机、车牌、带团人数，并填入对应字段。
4. 所有自动识别的字段内容，均可手动修改或完全手工填写。
5. OCR 识别失败时，不阻断手动填写流程。

---

### 模块四：费用智能录入

#### US-05：餐费录入

**作为** 导游  
**我想要** 通过语音或拍摄菜单 OCR，快速录入餐费信息  
**以便** 在忙碌的带团用餐时，动口不动手，准确记录开销。

**验收标准：**
1. 支持口语指令，如「4月11日微商酒店，中餐，人均40，10人」，识别并自动填入：日期、餐厅名、单价、人数。
2. 支持拍摄结账单/菜单，OCR 识别出餐厅名、日期、总价并填入表单。
3. 系统根据「单价 × 人数」实时自动计算小计，小计不可手动修改。
4. 无网络时，语音和 OCR 入口置灰，提示离线不可用，但手动输入全功能正常。

#### US-06：景点门票及电瓶车录入

**作为** 导游  
**我想要** 批量快速录入门票与电瓶车费用  
**以便** 处理多景点、多票种的复杂账目。

**验收标准：**
1. 支持语音批量录入，如「4月12日，虎跳峡，全票10张，免票2张，电瓶车20人」。
2. 支持拍摄门票实物，OCR 识别日期、景点名称、票种（全/优/免）和价格。
3. 表单字段严格根据模板显示（如票种单元格“全/优/免”），自动计算小计。

#### US-07：购物录入与多币种汇率计算

**作为** 导游  
**我想要** 在购物报账时，分别录入人民币、美金、韩币的消费金额，并录入当日汇率  
**以便** 系统自动换算为人民币小计，完全符合手工报账表的填写规范。

**验收标准：**
1. 购物录入页严格按模板分为「人民币」「美金」「韩币」输入框。
2. 提供「汇率设置」按钮，可手动输入美金、韩币的当日汇率。
3. 系统自动计算小计 = 人民币 + (美金 × 美金汇率) + (韩币 × 韩币汇率)。
4. 汇率默认记忆上次输入值，可直接使用或修改。
5. 模板中“提成比例”等无关字段，在此处完全不显示。

#### US-08：自费/加点与其他支出

**作为** 导游  
**我想要** 灵活录入自费项目、司机小费等杂项开支  
**以便** 覆盖行程中所有非标准费用的记录。

**验收标准：**
1. 语音支持识别「丽江司机小费400」、「足浴8人每人120」等自然口语指令。
2. 对于无固定名称的“其他支出”，支出名称栏允许完全自由输入。
3. 不同场景（自费看点/其他支出）在 UI 上以模板定义的区域做视觉区分。

---

### 模块五：凭证管理

#### US-09：费用凭证上传与查看

**作为** 导游  
**我想要** 为每一笔开销拍摄发票或付款截图作为报账凭证  
**以便** 凭证能与具体费用项和最终账单绑定，防止扯皮。

**验收标准：**
1. 每笔费用明细旁，均有「添加凭证」图标，支持拍照或相册上传。
2. 图片格式限定 JPG/PNG，单张自动压缩至 ≤2MB。
3. 上传后可查看缩略图，点击放大预览，并支持删除和替换。
4. 导出 PDF 报账单时，可选“附带凭证图片”，图片附于文件末尾。

---

### 模块六：自动计算与预览

#### US-10：实时自动计算

**作为** 导游  
**我想要** 在录入数字时，看到各项小计、合计和总金额实时自动更新  
**以便** 无需动笔或计算器即可掌握整个团的成本。

**验收标准：**
1. 单条费用小计、分类合计（餐费合计等）、全单总金额均自动计算（延迟 < 0.5s）。
2. 所有计算结果为只读状态，不可手动修改，金额保留两位小数。
3. 涉及其它币种的汇率换算同步自动计算。

#### US-11：报账单预览与 1:1 格式导出

**作为** 导游  
**我想要** 生成并导出一份与我上传的 Excel 模板排版、样式 100% 一致的报账单  
**以便** 直接提交给财务，省去二次排版的麻烦。

**验收标准：**
1. 点击「预览报账单」，系统将全量数据填入原始 Excel 模板副本，生成最终表。
2. 生成的表格必须完全复刻原模板的：合并单元格、列宽行高、字体样式、边框、背景色。
3. 支持导出为 `Excel(.xlsx)` 和 `PDF`。Excel 可再次编辑，PDF 版式固化防篡改。
4. 支持直接唤起微信打印功能，连接蓝牙/Wi-Fi 打印机打印。
5. **所有生成、预览、导出操作全程不依赖网络，离线可用。**

---

### 模块七：本地数据管理

#### US-12：历史报账单管理

**作为** 导游  
**我想要** 在“我的报账单”中查看、复制或删除历史记录  
**以便** 追溯之前的报账情况，或基于旧档快速建新单。

**验收标准：**
1. 按创建时间倒序展示所有本地报账单。
2. 可进入查看详情，回看每一笔费用与凭证。
3. 支持“复制为新报账”功能，可修改后作为新单据提交。
4. 删除报账单时须二次确认，并提示“数据仅存于本地，删除无法找回”。
5. 小程序缓存接近上限时，主动提示用户清理。

## 非功能需求（跨故事约束）

### NFR-01：离线能力

**作为** 导游  
**我想要** 在网络极差的山区也能正常记录和导出账单  
**以便** 不因信号问题中断工作。

**验收标准：**
- 全功能除“微信登录、语音识别与 OCR 识别”外，录入、计算、生成、导出、凭证管理均须原生支持离线使用。
- 无网络时，语音/OCR 按钮置灰并给予友好提示，不得阻断手动录入。

### NFR-02：数据隐私与本地安全

**作为** 导游  
**我想要** 我的所有财务数据仅存储在手机本地  
**以便** 不用上传云端，彻底保障我的商业隐私。

**验收标准：**
- 所有模板、单据、凭证均存储在微信小程序分配的本地文件系统。
- 本地数据须经混淆/轻量加密存储。
- 启动时明确提示：**“数据仅存储于手机本地，删除小程序将导致数据永久丢失”。**

### NFR-03：户外友好型 UI

**作为** 导游  
**我想要** 界面在户外强光下能看清，并支持单手操作  
**以便** 一边带团一边操作，无任何使用门槛。

**验收标准：**
- 字体、按钮大小适配户外可视性，关键操作位置处于屏幕下半部分（热区）。
- 新建报账 → 导出，核心操作不超过 5 步。
- 提供新手图文引导，首次使用关键功能时有指引。
